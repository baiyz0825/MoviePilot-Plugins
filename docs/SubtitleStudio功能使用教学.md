# 字幕工坊功能使用教学

本文适用于：

- MoviePilot V2 + 字幕工坊 `1.0.0`
- MoviePilot V3 + 字幕工坊 `2.0.0`

V2 和 V3 的页面、配置字段、导出命名和任务行为一致。差别只在插件内部对接的 MoviePilot 接口：V2 用 `app.plugins` / `httpx` / `tmdbid`，V3 用 `app.sdk` / `httpx2` / `media_source+media_id`。

字幕工坊是独立插件，**不委托**其它字幕插件。搜索、识别、翻译、特效顶注、导出和工作台预览都在本插件内完成。本仓库已下架海拉鲁字幕大师和 AutoSubv3，安装本插件即可。

## 一、安装插件

1. 在 MoviePilot 第三方插件仓库中添加：

```text
https://github.com/baiyz0825/MoviePilot-Plugins
```

2. 打开「插件市场」，搜索「字幕工坊」。
3. V2 安装 `1.0.0`，V3 安装 `2.0.0`。版本号不能相同，避免 Release Tag 碰撞。
4. 安装完成后到「我的插件」确认状态为运行中。

### 启用与侧栏

在插件卡片菜单点「设置」，打开「启用插件」后保存。左侧会出现「字幕工坊」。

如果没有入口：

- 确认「显示侧栏入口」已打开；
- 刷新 MoviePilot 页面；
- 看日志是否有「加载插件：SubtitleStudio」。

## 二、四个一级页

侧栏只有一条「字幕工坊」。进入后用顶部四个分段切换，**不要**再做插件自己的底栏（宿主已经有底栏）。

| 页 | 做什么 |
| --- | --- |
| 媒体 | 拉取整理记录，按目录列出片子；勾选后「提交识别」，或点整张卡片进详情再入队 |
| 队列 | 看 P0 / P1 / P2，搜索标题，插队、改优先级、取消、重试 |
| 工作台 | 按时间轴改 cue，挂载视频看实际字幕效果 |
| 设置 | 完整 FIELDS，控件下有「干什么 / 开了会怎样」 |

手机宽度 `≤899px` 时：

- 顶部分段仍在，不会出现第二层底栏；
- 媒体是整卡进详情，不在窄屏挤三列；
- 插队、改优先级、批量操作走底部动作表；
- 复杂流程用宿主全屏对话框。

## 三、基础配置

### 启用插件

总开关。关闭后不接新任务；已经在跑的做到当前步骤结束。页面仍可看历史。

### 显示侧栏入口

只控制侧栏。关掉不会卸载插件。

### 任务完成通知

默认关。打开后走 MoviePilot 已配置的通知渠道，类型是「插件」。

「通知哪些结果」默认勾成功和失败，也可加跳过、取消。剧集多时建议只勾失败，或整项关掉。渠道要在 MoviePilot「通知」里启用，并允许「插件」类型。

## 四、入库与监控

入库有两路，**独立开关**，默认只用事件。

### 整理完成事件入队（默认开）

听 `TransferComplete`。MoviePilot 整理完成就建 P1 任务。比扫盘轻，这是推荐方式。

V2 会真正入队，不是空转。同一 `media_source + media_id + 路径` 五分钟内只建一次。

### 媒体目录监控入队（默认关）

盯媒体库目录的新增/变更，给网盘补拷、手工扔文件、事件丢了用。和事件可以同时开，防抖规则相同。

### 监控的媒体目录

多行输入，一行一个容器内绝对路径，用真实换行。不要把 `\n` 两个字符写进框里。

空：跟 MoviePilot 媒体库根走。

### STRM

STRM 另有开关。STRM **不做 ASR、不调轴**（没有本地音轨）。只能搜索外挂字幕再翻译。

额外 STRM 路径同样是多行绝对路径。

### 跳过规则

- 跳过中文资源：国语片默认不再做中字。
- 已有中字则跳过：旁边已经有中文外挂就放过。
- 最小体积：默认 10MB，防止花絮、样本入队。

### 入库策略

- `先搜后译`：先找外挂，没有再考虑 ASR。
- `只搜索`：只找外挂，不识别。
- `只识别翻译`：不搜站，直接 ASR 再译。STRM 会失败。

## 五、输出语言和导出包

目标语言最少 1 种、最多 3 种，**顺序就是字号层级**：

| 顺序 | 字号 |
| --- | --- |
| 第 1 个 | 100%（主语言） |
| 第 2 个 | 约 78% |
| 第 3 个 | 约 64% |

叠行默认「主下小上」。可改成「主上小下」。

导出预设（只改默认语言码和勾选，不是最终文件清单）：

- 媒体库 / MoviePilot：`default.chi.zh-cn`，对齐整理记录
- Plex：`chi` / `eng`，不标 default
- 飞牛影视：`chs`（飞牛不认 `zh-Hans`）
- Infuse / 网页：`zh-CN`，并再勾 VTT
- 兼容旧库：`chi` / `chi&eng`

版式可多选：单语 / 叠行 / 分轨。格式可多选：SRT / ASS / VTT。**不生成** SUB/IDX/PGS。

### ASS 样式

设置页可改字体、主色、描边、多行小字号，带叠行预览。样式只写入 ASS；SRT / VTT 由播放器自己排版。

覆盖策略：跳过 / 备份后替换 / 直接覆盖。

设置页会按当前勾选预览将要写出的文件名。

## 六、搜索、翻译和识别

### 搜索偏好

搜索语言和来源（SubHD / Zimuku / ASSRT / OpenSubtitles）只影响「去哪找」，**不等于**导出包。导出由上面的语言和版式决定。

### 翻译后端

- `免费引擎优先`（默认）：Edge / GTX 等先译，缺句再走大模型。
- `仅免费引擎`：不消耗大模型额度。
- `仅大模型`：整片走 LLM。

研究、质量评判、纠错仍走大模型角色，不走免费引擎。

### 格式修复

模型偶尔吐 Markdown、尾逗号、缺 id。默认自动修：抽出 JSON、按 id 对齐、好句子先收下。缺的那句保留原文并记问题，**默认不写「[翻译失败]」**。

不要用现网那种「失败率超过 30% 整片作废」的默认。只有你主动打开「失败率过高则整片不写」才会 abort。

### ASR

本地有外挂就不 ASR。Whisper 没装、STRM、只搜索策略都不会去拉模型。`Movie.en.asr.srt` 只有真正跑过识别才写。

## 七、特效字幕

总开关默认关。打开后才做这些，**不是卡拉 OK，也不是飞字**：

- 保留搜到的特效 ASS 注释/招牌；
- 人物/专名第一次出现写一句 8–16 字的顶注（`\\an8`）；
- 写不下的进 Briefing 轨；
- 可选 SDH。

检索失败标「未证实」，不编造空话。

## 八、队列

优先级 `P0 > P1 > P2`。

- **插队**：升到 P0，排到未运行队列最前。不打断正在跑的任务。
- **改优先级**：只改还没跑的。
- **搜索标题**：过滤当前列表。
- 低谷窗口：例如 `22:00-06:00`，跨午夜有效。P2 默认只在低谷跑。

并发默认 3，不要默认 10。

## 九、工作台预览

时间轴按 cue 的入点/出点排。点一条可改字、改时间。

挂载预览：

- 本地文件能播就播；
- STRM 或播不了就用字幕黑板，并写明原因；
- 预览 ASS 由当前 CueGraph **现场打包**，不要去读已经落盘的旧文件。

## 十、工作流和助手

斜杠命令：`/subtitle_studio_run`。

工作流动作：入队、插队、改优先级、导出、重试。

助手工具会先看本插件是否启用，再执行。不要在工具里直接操作别的字幕插件。

## 十一、常见问题

**还要装海拉鲁或 AutoSub 吗？**  
不用。本仓库已下架这两个插件，字幕工坊自己完成搜索到导出。其它来源如果还装着旧插件，不要同时开自动入库，避免同一部片子被处理两次。

**为什么 STRM 没有识别？**  
STRM 没有本地音轨，识别和调轴被硬跳过。只能搜外挂。

**为什么没写出 `.en.asr.srt`？**  
只有 Whisper 真正跑过才写。已经用了外挂源不会假造这条。

**手机上设置项很多怎么找？**  
设置页按「基础 / 入库 / 搜索 / 导出 / 特效 / 识别 / 模型 / 质量 / 队列」分组，手机用手风琴，每项下面有说明。
