字幕工坊 V1 设计说明

一个 MoviePilot 插件替代海拉鲁字幕大师和 AI字幕生成。搜、配、调轴、识别、翻译、特效补注、导出都在同一条持久化队列里。旧插件只作对照，运行时不互相调用。产品合同只有一份；宿主按官方规则拆成 plugins.v2/ 和 plugins.v3/ 两棵树，V2、V3 都要交。

一、V1 范围

要做完

媒体目录、在线搜索、解包匹配、调轴、STRM、入库入队、ASR（可保存原轨）、完整大模型线路、导出格式多选、特效、纠错工作台、术语表、Briefing、SDH、工作流。MoviePilot V2 与 V3 各交一棵独立树，产品页和导出合同相同。

默认先关、但 V1 必须有

目录监控、STRM 监控、特效字幕、SDH、错峰窗口默认关。整理完成事件默认开，觉得会刷任务再关。

明确不做

卡拉 OK、片头组名、满屏飞字；不生成 SUB/IDX/PGS。STRM 不做 ASR/调轴（没有本地音轨）。不为另一插件转临时 SRT。

二、信息架构

插件侧栏一个入口，页内四个一级页。海拉鲁的「媒体 + 一堆对话框」和 AutoSub 的「只有任务表」合成一套。

媒体

找片、对集、看已有字幕。

  • 搜索 / 海报 / 季集
  • 上传、在线搜、锁定
  • 入队生成

队列

所有任务的唯一列表。

  • 搜标题、插队、改 P0/P1/P2
  • 人工 / 事件 / 目录监控 / STRM
  • 取消、重跑、关特效

工作台

对着 CueGraph 改字，并挂上字幕看效果。

  • 时间轴 + 播放头
  • 视频/黑板在线预览
  • 纠错、术语、Briefing

设置

全局默认，任务可覆盖。

  • 搜索偏好 ≠ 导出包
  • 大模型线路：URL / Key / 模型 / 测连通
  • 格式多选；可保存 ASR 原轨

对话框只做短流程：上传预览、在线结果、写入确认、验证码、重跑选项。不再把 AI 队列和入库队列拆成两个弹窗。

现网 AutoSub 有端点池、URL、Key、模型、拉列表、测连通、代理、兼容模式、批量、并发、上下文、重试。说明书里不能只留「并发 3」。Whisper 在「识别」组，大模型在这一组。

每条线路要有的字段

名称、API URL、API Key、模型名、启用、是否主线路、使用代理、兼容模式。操作：上移下移、设为主线路、拉取模型列表、测连通、删除。至少留一条启用线路。

和现网的差别

不再把 URL/Key/模型只写在插件管理那三个框里当唯一配置。设置页里就是完整线路表。未绑角色时，四个角色都走主线路。fallback 按列表顺序，不是随机。模型吐脏 JSON 先修格式，不立刻整批判失败。

四 D、多语种顺序、背景顶注、免费翻译

目标语种：最少 1、最多 3，顺序即大小

顺序角色字号叠行默认位置
1主语种100%（约 22）主下小上时在下
2次语种约 78%（约 17）在上或夹在中间
3再次约 64%（约 14）最边上的小字

只勾 1 个：只出单语主轨，不叠行。勾到 3 个还要第 4 个时，界面禁止再加。最后一个不能去掉。ASS 用独立 Style（Lang1 / Lang2 / Lang3）设 Fontsize，避免抢同一个 Default。SRT 只能换行叠，字号靠播放器，所以要大小关系时默认再勾一份 ASS。

人物背景顶注（可关）

字幕组把人物介绍、背景知识做成顶部短注：ASS \an8 顶栏居中，或 \pos 贴屏字；Aegisub 排版说明也提醒不要把画面上每个词都注满。V1 只做「首次出场一句摘要」，不做飞字和卡拉 OK。

  • 触发：专名或角色第一次在对白里出现，跟当前时码对齐，停 2–4 秒。
  • 长度：8–16 字；写不下进 Briefing，不把百科塞进对白。
  • 密度：每屏 1 条；和关键词梗注共享密度，避免上下同时开花。
  • 层：Layer 高于对白，低于屏字（若保留了下载的屏字）。
  • 开关：挂在「支持特效字幕」下，默认随总闸；总闸关则完全不跑。
  • 失败：检索不到就标未证实，工作台可见，不上屏编造「很帅的男人」这种空话。

免费翻译引擎

对白不必只走大模型。字幕翻译工具常见组合是免 Key 的 Edge / GTX，再加上 Google、微软、DeepLX、自建 LibreTranslate，见 subtitle-translator 与 Lingarr。

引擎钥匙适合注意
Edge / GTX免 Key默认第一档对白有限流，译文直
Google / 微软可选免费额度备选要 Key 或额度
DeepLX自建想接近 DeepL公共节点不稳
LibreTranslate自建地址不出网中文质量一般
大模型线路URL/Key对白润色、质检、人物检索人物背景摘要优先用它压缩

策略默认「免费引擎优先」：对白先免 Key，失败再大模型。人物/梗检索不走免费引擎硬译百科。只开免费引擎、又开了特效时：顶注用维基首句截断，质量差的进工作台标「未压缩」。

四 C、模型输出格式自动修复

现网批量翻译只要行数不对、id 顺序不对、JSON 多一句解释，整批就降级逐行；失败率过 30% 整片不写。Whisper 出来的重叠轴、空句也原样落盘。V1 先修格式再谈失败，用来提高成功率，不改句子意思。

修的是格式，不是再创作

自动修复只处理围栏、编号、JSON、时间轴、空句。不把译文「润色」成另一套词。语义问题进工作台或质检角色，不在这一步偷偷改。

识别（Whisper）出来先修一遍

常见脏输出现网V1 自动修
空句、纯「嗯/啊」、连续重复幻觉原样进 SRT丢掉或合并，记一条低置信 Issue
结束时间早于开始、两句重叠播放器里闪或倒播交换或裁到上句结束 + 40ms 间隙
一句跟太久 / 一行太长50 字一刀切，中英一样按时长和中英 CPS 切开，最多两行
识别结果里夹着 SRT 序号或时间戳文本译进去变成乱码进 CueGraph 前剥掉

翻译 / 质检 / 纠错 / 检索：先修再降级

阶做什么现网

为什么能提高成功率

中转模型经常在 JSON 前后加一句「好的」。现网当整批失败。修好格式后，同一条响应就能用。缺 2 句只补 2 句，不必 20 句重打。

不自动修什么

人名译错、漏译、语气不对：交给质检和工作台。卡拉 OK 标签、飞字特效：明确不做。检索未证实的词条：标出来，不编圆。

保存 ASR 原轨

现网只写翻译结果，Whisper 出来的原文轨用完就丢，重译还得再识别。V1 加开关，默认开：只要这次走了 ASR，就额外落一份源语言字幕，不标 default，播放器里当普通外挂。

什么时候写

开关开，并且任务源是 Whisper。用了在线包、本地外挂或内嵌，不写这份。STRM 不会 ASR，因此也不会有。

写成什么样

最终路径两代相同：/api/v1/plugin/<PluginID>/<path>。宿主不会替插件包一层。不要设匿名，除非真是公开接口。页面调用 auth: "bear"；外部自动化可用 apikey。V3：每个普通 JSON 端点必须声明具体 response_model，能在 /docs 查到，不要用 dict / Any 当长期模型。V2：官方不强制 schemas.Response[T]，但产品仍回同一套 {success, message, data}，共享 Vue 只写一套解析。

宿主普通 JSON（插件去调主程序时）固定三段，不要多顶层字段，业务只放 data：

{ "success": true, "message": "", "data": {} }
  • 查询已完成但没记录：success=true，用 data 表示空。空查询不要 success=false，否则前端当失败 Toast。
  • HTTP 200 + success=false：调用完成但业务拒绝。参数错、未认证、不存在用 HTTP 状态 / HTTPException。
  • message 禁止写堆栈、Cookie、令牌、内部路径。不要恢复顶层 message_i18n。
  • Python 调宿主：先 raise_for_status()，再检查三字段和 success，只取 data。/api/v2 已废，一律 /api/v1。
  • Vue：不要 payload.data.data，不要再拼 /api/v1/。envelope 失败默认已 Toast，插件不要弹第二次。轮询用 { feedback: 'silent' }；要显示成功文案用 feedback: 'all'。
  • 测试 mock 最终 payload，不是 AxiosResponse。

远程命令格式：

处理时必须先判断 event.event_data.action 是不是自己的，否则会吃到别人的 PluginAction。消息按钮回调：EventType.MessageAction，先比 plugin_id == self.__class__.__name__；按钮 callback_data 必须是 [PLUGIN]插件ID|内容。

自动入队有两路，开关互不影响：ingest_on_event 听 TransferComplete（默认开，现网海拉鲁就是这条）；ingest_on_watch 是插件自建的媒体目录 watchdog（默认关）。两路都开时，同一身份键 + 路径 5 分钟内只建一次。身份键：V3 用 build_media_key(media_source, media_id)；V2 从 transferinfo / mediainfo 取 tmdbid / doubanid，能合成 themoviedb:id 就合成，否则用路径。事件回调里只挂 3 秒防抖任务，不要当场打满字幕站——V3 用 add_plugin_once_job，V2 用 DateTrigger + replace_existing。STRM 是第三路自建 watchdog，不是宿主事件，也不做 ASR/调轴。现网 AutoSub V2 的 TransferComplete 监听是空转再去扫盘；新产品 V2 必须真正入队，不要学那条空转。
